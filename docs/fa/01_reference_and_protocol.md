# AMI-100 参考标准与评测协议

本次原始输入为 `/mnt/data/L202500293/obed/mfa/datasets/ami-100/manifest.jsonl`。不修改原始数据。100 条，466.36 秒，758 个参考词。headset 34 条、noise10 33 条、mixed 33 条；ES2004a 与 IS1009a 各 50 条。准确的唯一事件数及文件摘要见 `results/fa/evaluation.json` 和 `provenance.json`。

## 金标准选定结论

**现有资料中没有独立人工逐词时间边界金标准。** 选择 manifest 的 AMI 官方逐词时间戳作为全量、可复现的**银标准**。不把模型相互一致、MFA 输出或 Nyra 输出当成人工真值。AMI 的文本经过人工转录和复核，不能由此推断词边界也是人工精标。官方明确说明词及音素时间来自 forced alignment：[AMI Transcription](https://groups.inf.ed.ac.uk/ami/corpus/transcription.shtml)。来源归因、原始音频/标注 zip 的摘要在原数据 `source-provenance.json`；源标注为 AMI manual 1.6.2，CC BY 4.0。

因此这里的“准确性”专指与既有参考的相符程度。结果不构成对真实声学词边界的绝对准确率证明，也不能凭与参考不一致断言某模型错误。不能把自动过滤的子集升级为人工金标准。

独立人工金标准采用以下验收规则：由熟悉英语语音边界的标注者逐词听音并观察波形/频谱，在 headset 上标边界；同步 mixed/noise10 继承相同的事件边界。跨说话人重叠、片段词、无法分辨的内容保留单独标签。双人独立标注、差异超过 40ms 的边界交由第三人裁决；记录 reviewer、版本、置信度和修改原因。先冻结金标准，再评测，标注时隐藏模型名字与预测边界，避免模型先验偏差。当前 `review.csv` 中人工边界列全部空白，状态 pending，未声称完成听审。该文件是问题复核队列，带有模型预测；若制作盲标金标准，需向标注者另行隐藏预测列，并补充随机抽样的正常对照，不能只标异常词。

## 双口径

- 完整参考：全部 758 词，不以参考质量为由隐藏失败。
- 过滤参考：仅保留起止合法、正时长，且 `reference_duration_suspicious`、`truncated`、`overlap` 均为 false 的词。过滤只影响计分，**不删除对齐输入中的词**。这些标签不进入路由。

音频使用 manifest 提供的相对片段时间，不能再次加 offset 后与片段预测比较。发布到整场会议时才加 offset。mixed 是同步 headset 的算术平均，不是官方远场麦克风，也不是源分离结果。noise10 的生成方法依原数据准备脚本及 provenance，不将其等同真实所有噪声场景。

## 两条实验轨道

1. **参考文本 FA**：同一 manifest 文本送给 Qwen、MFA、Nyra，只比较对齐。
2. **真实 ASR → FA**：本地 Qwen3-ASR-1.7B 重新识别全部音频，将同一份识别文本送三模型。文本插入、删除、替换单独统计；只对与参考词匹配的词计时间误差，同时报告参考覆盖率及缺失数。ASR 词没有匹配参考，不等于幻觉：可能是标注遗漏或分词差异，不能自动判定为不存在的声音。

Nyra 输入仅将独立 token `um/uh` 转成 `[UM]/[UH]`，输出恢复；不利用参考的 truncated 标签补词或改写文本。MFA 使用 english_mfa 3.1.0 与 english_us_mfa 3.1.0，beam 400、retry_beam 4000。较宽 beam 作为预先固定配置，未拿验证集挑 beam。具体运行选项见运行日志及 runtime.json。

## 指标与问题定义

词匹配使用大小写/外围标点归一化后的 Levenshtein 动态规划；重复词保序，替换不计为时间匹配。不按文本字符串字典索引，避免覆盖重复词。保持撇号内部拼写，分词差异必须列入覆盖统计，不捏造拆分词的边界。

- 词 MAE = (|预测起点−参考起点| + |预测终点−参考终点|)/2；报告均值、中位数、P95。
- 大偏移：词 MAE >100ms；严重偏移 >200ms；另统计任一边界 >100ms，不能混用这两种分母。
- 时间 IoU = 区间交集长度/并集长度；<0.5 为低重合。
- `zero_duration`：预测 end−start ≤1e-6 秒（排除负时长）；`short_duration`：0<时长<40ms；`long_duration`：>1.5s。后两项是可疑信号，长拖音/短功能词可能合理。
- `negative_duration`、`nonfinite`、`nonmonotonic`：负时长、非有限数、起点逆序。
- `out_of_bounds`：超出 [−20ms, clip_duration+20ms]。
- `overlap`：当前起点早于前一词终点超过 20ms；它与多人真实重叠不是同一概念。
- `missing_or_substituted`：参考词没有完全词形匹配。完整文件缺失/模型异常单独保留，不能从样本分母消失。

类别可以重叠，分类计数之和不能解释为不同错误词总数。用“category_removed”报告结构问题消失；用“timing_rescued_le100ms”报告同时达到时间误差要求，不能把非零时长直接叫做正确对齐。

## 验证设计与局限

按会议固定开发 ES2004a、验证 IS1009a；同一 base_id 的音频变体不得跨集合。只在开发集拟合路由条件和回退后端，验证集只运行冻结策略。只包含两个会议，泛化证据有限；本次存在银标准偏差、词间边界定义差异、短反馈词及参考极长词等问题。过滤口径会改变困难词比例，完整集结果必须同时展示。没有真实 ASR 标准词的词不能用 FA 强行“修好”；应转为转录复核。
