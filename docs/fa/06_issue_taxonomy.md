# 问题分类、机制和未解决项

## 零时长机制

实际下载的Qwen config中 `timestamp_segment_time=80`（毫秒）。本次qwen-asr0.0.6源码先把预测类别乘这一量化步长，再调用 `fix_timestamp` 做非严格单调修正，允许相同起止时间。它不保证每个词正时长。可核对 `models/qwen3-forced-aligner/checkpoints/config.json` 以及运行环境 `qwen_asr/inference/qwen3_forced_aligner.py`。

77个零时长词对应的参考时长中，只有16个≤80ms。其余不是简单的“真实短词小于时间分辨率”即可解释；参考本身可能不精确，模型压缩、弱语音或内容不匹配也可能参与。未保存原始未修正logit，不能定量拆分后处理与声学预测各自贡献。

最长连续塌缩例为 `ES2004a_D_000_noise10` 的5词；不应把同一时刻的词均分成假定时长。fillers只占6个零时长词，其余71个是普通词，因此不能只路由um/uh就声称解决零时长。

| 音频条件 | 参考词 | 零时长词 | 词MAE>100ms |
|---|---:|---:|---:|
| headset | 282 | 12 | 66 |
| noise10 | 163 | 33 | 68 |
| mixed | 313 | 32 | 96 |

## 汇总分类

| 类别 | 证据/检测 | 处置 |
|---|---|---|
| 时间结构 | 零/负/非有限、逆序、超界、输出词间重叠 | 规则回退；失败后复核，禁止捏造时间 |
| 精细边界偏差 | MAE、IoU、100/200ms尾部 | 使用双口径参考计分；保留替代模型退化 |
| 时长异常 | <40ms或>1.5秒 | 仅为可疑；回退不得新增超长词 |
| 序列完整性 | DP遗漏、替换、额外token、Nyra skipped | 数字/分词/OOV规范化或转录复核 |
| 内容/说话人范围 | 混音ASR多转录其他人的语音 | 上游说话人约束；FA不负责判断真实说话人 |
| 参考不确定性 | 290词带可疑时长/截断/重叠等排除原因 | 双口径报告，独立人工盲标后再定结论 |
| 候选回退退化 | 新增长词、稳定锚点跳变>500ms | 拒绝整段回退并标needs_review |

剩余：AMI-100混合仍有52个零时长输出，真实ASR轨道仍有73个。结构正常也可能声学错位；guard可能挡住正确的大幅修复，不能将它称为真值判别器。应优先人工复核 `review.csv` 中的连续塌缩、数秒偏移、说话人范围及参考异常，再扩充独立金标准。
