# 真实 ASR → FA 评测

本次用本地 Qwen3-ASR-1.7B 对全部100条音频重新识别，再把同一份识别文本送三套 FA；V2 使用参考文本开发得到的冻结路由，未在 ASR 结果上重调。输入和三方结果位于 `results/fa/asr.jsonl`、`asr_manifest.jsonl`、`asr_eval/`。

参考758词，ASR输入874个空白分词 token。与参考严格词形 DP：匹配600，删除60，插入176，替换98；表观词错误率44.06%。该值包含目标说话人范围和分词差异，不能等同于独立听审的识别错误率。

| 系统 | 完整参考 MAE ms | 过滤参考匹配/总词 | 过滤 MAE ms | 过滤坏词/未匹配 | 输出零时长 |
|---|---:|---:|---:|---:|---:|
| qwen | 169.32 | 409/468 | 102.22 | 136 | 85 |
| mfa | 527.90 | 410/468 | 318.37 | 139 | 0 |
| nyra | 127.98 | 409/468 | 60.01 | 105 | 0 |
| hybrid | 163.60 | 409/468 | 95.72 | 127 | 73 |

零时长输出口径：Qwen85个，混合73个；Nyra/MFA无零时长，但不因此认定对齐正确。过滤参考上混合 MAE 从102.22ms降至95.72ms；纯Nyra为60.01ms，明显优于本次Qwen主导策略。这说明Qwen主导约束存在准确性代价，不能宣称混合优于所有单模型。

Nyra 在 `ES2004a_A_004_mixed` 跳过 `1.4`，造成1个输入 token 没有时间；数字的实际读法可能是 one point four 等，需要转录规范化/人工核对，不能随意假定。MFA 输出有拆分/替换 token，详见 insights 的输入完整性统计。

## 内容范围问题

`IS1009a_C_013_mixed`：参考目标说话人文本结束于 user interface design；ASR 还识别出其他人的 Very good、项目经理介绍等内容。`IS1009a_B_013_mixed` 和 `ES2004a_C_013_mixed` 也出现超出目标参考文本的内容。这些内容可能真实来自其他说话人；本次没有听审证据把它们叫作“幻觉”。FA无法仅靠转录确定目标说话人，应先做说话人约束/转录复核。

不能仅对参考匹配词的 MAE 排名而隐去覆盖率：本轨道过滤参考中Qwen、Nyra、混合均只匹配409/468词，59词无匹配。MFA的410词覆盖差异还受到分词影响，并不表示FA修复了ASR识别。

参考文字轨道与真实ASR轨道的误差不能直接相减当作ASR造成的损失，因为计分词集合不同。
